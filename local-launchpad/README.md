# Local Launchpad

A no-dependency starter for selling a focused local-business website refresh. It provides a simple prospect pipeline and a realistic service offer. It does not send messages, scrape businesses, claim guaranteed results, or require an AI API subscription.

## Run it

Open `index.html` in a modern browser. The app is static; there is no server or build step. Prospects are stored in that browser's local storage. Use **Export leads** to make a CSV backup before changing browsers or clearing browser data.

## The business model

Offer a fixed-scope, mobile-friendly one-page website refresh to a local business whose public website has a clear, fixable usability issue. The sample $350 starting price is illustrative: confirm your skill, local market, scope, costs, and payment terms before quoting. A practical next step is to make one polished sample refresh for a fictional business, then use it to explain the service. Do not present a mockup as client work or promise traffic, rankings, or revenue.

## Workflow

1. Identify a business you can genuinely help and review public business information.
2. Record one factual, respectful observation and a specific improvement idea.
3. Prepare a small sample or audit and an honest, personalized introduction.
4. Review applicable outreach laws and platform rules, send only manually where appropriate, and honor opt-outs.
5. Track responses and learn from them before increasing volume.

The application has no network calls, AI generation, outreach automation, authentication, or cloud sync. Anyone with access to this browser profile can see its local data. Do not store sensitive personal information. Keep a separate CSV backup. Revenue is not guaranteed; finding buyers and delivering paid work still requires judgment and human effort.
